# TaleWeaver Adventures

Welcome to the official repository for **TaleWeaver** adventures! This collection contains curated adventure blueprints, settings, and storylines designed to be played with the [TaleWeaver Engine](https://github.com/jschm42/taleweaver).

TaleWeaver is a generative AI roleplaying engine that uses Large Language Models and cinematic Text-to-Speech to create immersive, dynamic narratives. This repository serves as a library for sharing and preserving these created worlds.

## 📂 Repository Layout

Every adventure lives unpacked in its own directory at the repository root:

```
<slug>/                     one directory per adventure
  adventure.adv             blueprint (JSON)
  assets/                   scene images, portraits, cover art
  README.md                 short summary
library.json                index the TaleWeaver app reads (generated, do not edit)
scripts/add_adventure.py    unpacks a .adz into <slug>/ and regenerates library.json
Concepts/                   ideas and world-building notes that are not yet full blueprints
```

The authoritative identity of an adventure is `adventure.origin_id` inside
`adventure.adv`; it is the `id` in `library.json`.

## ➕ Adding or Updating an Adventure

1. Export the adventure from TaleWeaver as a `.adz` file.
2. Unpack it into the repository (Python 3.10+, standard library only):

   ```bash
   python scripts/add_adventure.py path/to/my-adventure.adz
   ```

   * A new adventure gets a directory named after its title (override with `--slug`).
   * An existing adventure (same `origin_id`) replaces its directory completely, so
     removed assets disappear as well. Its `README.md` is kept.
   * Overlong asset file names (over 80 characters, typically from repeated exports)
     are shortened and their references in `adventure.adv` are updated, so paths stay
     well below the 260-character limit on Windows.
   * `library.json` is regenerated from all directories.
3. Review the diff, then commit and push. That is the release - there is no other step.

After editing a directory by hand, regenerate the index with
`python scripts/add_adventure.py --rebuild`.

## 🚀 How to Use

**In TaleWeaver:** open the adventure library in the portal and install an adventure.
The app reads `library.json` and fetches the listed files of that adventure directly
from this repository.

**Manually:** zip the *contents* of an adventure directory into a `.adz` and import it
through the **Import Adventure** button in the TaleWeaver library:

```bash
cd kitchen-crisis && zip -r ../kitchen-crisis.adz adventure.adv assets
```

## 🛠️ Adventure Formats

*   **`.adv` (JSON):** The core blueprint of an adventure. It contains the world manifesto, scene definitions, NPC data, and RPG mechanics.
*   **`.adz` (ZIP):** An "Adventure Zip" package: `adventure.adv` at the archive root plus an `assets/` folder with scene images and character portraits.
